# Changelog

All notable changes to Nar Shaddaa Sabacc are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-11-22

First public release, as an open beta: bugs are likely, balance and UI may still change. Feedback is welcome!

### Added

- Nar Shaddaa Sabacc card game: 2 to 6 players, droids with 3 difficulty levels, rule variants, tournament mode
- Portable game terminal (inventory item), menus, spectators, statistics, sounds
- Physical Sabacc tables placed in the editor, with the same settings as the module: seated players, the real cards, chips and shift tokens on the felt, matching stools
- Dealer droid floating above each table: turns to the player in turn, shows what happens as holographic messages, floating dice under it
